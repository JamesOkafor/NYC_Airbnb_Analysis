# NYC_Airbnb_Analysis
Exploratory Data Analysis (EDA) of Airbnb listings in NYC using the 2019 dataset. includes insights on pricing, neighbourhoods, availability, and room types using Pandas, Seaborn, Matplotlib, and NumPy.

##  Dataset

- **Name:** `AB_NYC_2019.csv`
- **Source:** [Kaggle](https://www.kaggle.com/dgomonov/new-york-city-airbnb-open-data)
- **Attributes:** ID, name, host_id, neighborhood_group, neighborhood, latitude, longitude, room_type, price, minimum_nights, availability_365, etc.


##  Objectives

The analysis aimed to:
- Understand the distribution of listings across neighborhoods
- Analyze pricing trends by room type and location
- Detect outliers and irregularities
- Visualize key insights about availability and popularity


##  Tools & Libraries

- Python 3.x  
- `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`  
- Google Colab


##  Key Analysis Steps

1. Loaded and examined the dataset structure
2. Cleaned missing or invalid data
3. Checked unique values and duplicates
4. Reviewed neighborhood and room types
5. Explored price distribution
6. Detected outliers using boxplots
7. Visualized room types vs price using bar charts
8. Grouped prices by neighborhood
9. Analyzed minimum nights required
10. Reviewed listing availability
11. Mapped listings using latitude and longitude
12. Analyzed top hosts
13. Correlation analysis between price, nights, availability
14. Created scatter and distribution plots
15. Provided final observations and recommendations

##  Final Observations

- **Manhattan** and **Brooklyn** have the highest prices
- **Private rooms** dominate the market but **entire homes** have higher pricing
- There are significant price outliers needing attention
- Listings with excessive minimum nights may not be customer-friendly


##  Conclusion

This analysis provides valuable insights into Airbnb’s NYC market. These insights can guide hosts, investors, and platform strategies to improve user experience and maximize profit.
